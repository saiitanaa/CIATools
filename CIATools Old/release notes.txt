## What's New

- Change in Python script execution

**Before:**
`Process.Start("cmd.exe", $"/c cd /d \"{execute_py}\" && python import.py");`

**After:**

`Process.Start("cmd.exe", $"/c cd /d \"{execute_py}\" && py -3 import.py");`

Software like MSys2 causes Python to redirect to them, which creates invalid path errors.
