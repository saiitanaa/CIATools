# CIATools | SMDH-Creator

## SMDH-Creator for CIATools

**RSF-Creator** is a tool designed to run on CIATools that allows you to **create .smdh configuration** files very quickly and easily.

**CIATools repository**: https://github.com/saysaa/CIATools

---

## How to use ?

Open CIAToolsR and goto Toolbox and click : Start SMDH-Creator

---

## Compile

**For Windows** : `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`

**For Linux** : `dotnet publish -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true`
